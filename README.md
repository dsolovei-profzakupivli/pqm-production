# Prozorro Qualification Manager (PQM) 0.1

Локальна серверна версія першого екрана **«Реєстр заявок»**.

## Поточний стан

У базу вже завантажено реальний відбір:

- `UA-F-2020-12-15-000010-a`;
- 2 360 заявок `Submission`;
- 2 360 рішень `Qualification`.

PQM використовує справжній `submission.id` як прихований ключ заявки. Штучні номери на зразок `A-1041` не використовуються.

## Запуск на Windows

1. Встановіть Python 3.12 з [python.org](https://www.python.org/downloads/windows/), якщо його ще немає. Під час встановлення позначте `Add Python to PATH`.
2. Відкрийте папку `PQM-0.1`.
3. Двічі клацніть `start.bat`.
4. Застосунок автоматично відкриється за адресою `http://127.0.0.1:8080`.
5. Не закривайте консольне вікно, поки працюєте з PQM.
6. Для завершення роботи закрийте консольне вікно.

Сторонні Python-пакети не потрібні.

## Що реалізовано

- локальний HTTP-сервер;
- база SQLite у `data/pqm.sqlite3`;
- синхронізація Framework, Submission і Qualification з Prozorro API;
- коректна пагінація вкладених endpoint-ів Prozorro;
- реальний реєстр із серверною пагінацією по 50 записів;
- серверний пошук і фільтр за статусом рішення;
- документи заявки та рішення через скріпку;
- редагування внутрішніх полів УО;
- масове заповнення погоджених полів;
- ролі «Перегляд», «УО» та «Адміністратор»;
- блокування полів після остаточного рішення, крім примітки;
- серверний журнал змін;
- профілі колонок у браузері;
- кнопка оновлення даних із Prozorro.

## Джерела та власні поля

Із Prozorro надходять відбір, постачальник, ЄДРПОУ/РНОКПП, дата заявки, документи та рішення. Внутрішні поля PQM зберігаються окремо й не перезаписуються синхронізацією:

- номер протоколу;
- дата протоколу;
- дата публікації рішення;
- УО протоколу;
- прізвище, ім’я, по батькові керівника;
- пакет документів;
- примітки.

ПІБ керівника на цьому етапі вводить УО. Інтеграція з Clarity Checker не входить до поточної версії.

## Структура

- `server.py` — сервер, схема бази, API та синхронізація;
- `data/pqm.sqlite3` — локальна база;
- `index.html`, `styles.css`, `app.js` — вебінтерфейс;
- `start.bat` — запуск на Windows.

## Резервне копіювання

Коли PQM не запущений, скопіюйте файл `data/pqm.sqlite3` у безпечне місце. У ньому містяться всі внутрішні поля та журнал змін.

## Наступний етап

Поточна синхронізація підключена до одного еталонного відбору. Наступне розширення — автоматичне отримання всіх Framework організатора з ЄДРПОУ `40996564`, одноразовий імпорт історії та інкрементальне оновлення активних відборів.
