# TEST database procedure — база навмисно відсутня

Робочу LOCAL `pqm.sqlite3` до пакета не включено: вона містить ручні/службові та персональні дані. Повна ProzorroBids DB (~31.9 GB) також виключена.

Найбезпечніший варіант для першого оновлення існуючого TEST WEB:

1. На Render зафіксувати шлях і розмір поточної TEST SQLite.
2. Створити актуальний snapshot persistent disk.
3. Зробити SQLite `.backup` старої TEST-БД у **новий файл**, наприклад `/var/data/pqm_test_20260830.sqlite3`; старий файл не змінювати.
4. Для копії виконати `PRAGMA integrity_check;`, `PRAGMA foreign_key_check;`, контрольні counts і SHA-256.
5. Встановити `PQM_DB_PATH=/var/data/pqm_test_20260830.sqlite3` та розгорнути код на копії.
6. Не переносити цю TEST-БД у майбутній PROD.

Якщо керівник не може підтвердити вміст, резервну копію та відсутність production-даних — створення/підключення TEST-БД зупинити. Порожня окрема SQLite може використовуватися лише для container smoke, не для предметного приймання.
