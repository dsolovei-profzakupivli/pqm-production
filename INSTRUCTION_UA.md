# Як запустити PQM на іншому ноутбуці

## Що потрібно

- Windows 10 або Windows 11;
- Python 3.12;
- доступ до Інтернету для першого встановлення залежності `python-docx` та для звернень до відкритих джерел Prozorro;
- щонайменше 3 ГБ вільного місця після розпакування.

## Перший запуск

1. Скопіюйте ZIP-файл на локальний диск і повністю розпакуйте його. Не запускайте PQM безпосередньо з архіву.
2. Якщо Python не встановлено, встановіть Python 3.12 з <https://www.python.org/downloads/windows/> і під час встановлення позначте **Add Python to PATH**.
3. Відкрийте розпаковану папку `PQM-0.1`.
4. Двічі натисніть `start.bat`.
5. Під час першого запуску може автоматично встановитися пакет `python-docx`.
6. Після запуску відкриється <http://127.0.0.1:8080>.
7. Не закривайте чорне консольне вікно під час роботи. Для завершення PQM закрийте це вікно.

## Що входить у пакет

- код локального вебзастосунку;
- контрольна копія бази `data/pqm.sqlite3` для перевірки поточного стану;
- довідники та поточні тестові дані;
- журнал проєкту та опис функціоналу.

## Важливі обмеження контрольного пакета

- Це тестова локальна версія. Ручні рішення, протоколи та зміни, внесені під час перевірки, зберігаються тільки в локальній копії бази керівника й не впливають на робочу копію автора.
- Велика база `ProzorroBids` не включена до архіву. Тому вкладки «Відбори» та «Закупівлі за відборами» показують збережені в основній базі відомості, але Bids-аналітика, ручне оновлення Bids і експорт Power BI потребують окремої бази ProzorroBids.
- Особисті Google OAuth-токени й секрети не включені. Закриті Google-таблиці не синхронізуються, доки перевіряльник окремо не налаштує власний дозволений Google OAuth-доступ.
- Для контрольного перегляду не потрібно натискати масове оновлення або синхронізацію довідників.

## Якщо сторінка не відкрилась

1. Перевірте текст помилки у консольному вікні.
2. Переконайтеся, що Python доступний командою `python --version` або `py --version`.
3. Перевірте, що порт `8080` не зайнятий іншим застосунком.
4. Повторно запустіть `start.bat`.

## Збереження результатів перевірки

Для передачі внесених тестових змін назад потрібно зупинити PQM і скопіювати файл `data/pqm.sqlite3`. Не копіюйте базу під час активного запису.
